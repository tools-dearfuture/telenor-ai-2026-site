# Telenor AI 2026: the published learning path

**This repo is a second repo on purpose. Do not delete it.**

It is the public shell that GitHub Pages serves from. It holds only the encrypted HTML of the
Telenor AI 2026 learning path (AES-256, decrypted in the browser with a password Dear Future shares
separately). Nothing here is readable without that password, which is why it can be public.

The content itself lives in the **private** source repo `tools-dearfuture/telenor-ai-2026`
(`path/**/*.md`, one file per task). That repo must stay private, and GitHub Pages on this account
needs a public repo, so the two cannot be merged: the source stays private, the ciphertext is public.

Everything in this repo is regenerated by `tools/publish_site.py` in the source repo on every publish.
Edits made here are overwritten. The URL `https://tools-dearfuture.github.io/telenor-ai-2026-site/telenor.html`
is quoted in STATUS.md, in the CXO pack and in the team's bookmarks, so the repo name must not change either.
